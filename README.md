# it-security-portfolio
Hands-on IT support and security labs with troubleshooting notes and verified results.

## Projects

### Linux Support Lab: SSH Access Investigation

Configured SSH access to an Ubuntu VM through VirtualBox NAT port
forwarding. Tested successful and deliberately failed password logins,
reviewed authentication logs, and practiced separating observations
from security conclusions.

[Read the case study](01-Support-Lab/Notes/ssh-access-investigation.md.txt)

[View screenshots](01-Support-Lab/Screenshots)

**Skills practiced:** Linux command line, SSH, NAT port forwarding,
systemd service inspection, journalctl, and technical documentation.

This project was completed in a personal lab using controlled tests.

### SSH Key Authentication

Configured and tested SSH public-key authentication between my Mac
and Ubuntu VM. Verified the login through authentication logs and
matching key fingerprints, and resolved a file-location error by
checking the active machine and account.

[Read the case study](01-Support-Lab/Notes/ssh-key-authentication.md)

**Skills practiced:** SSH key management, authentication log analysis,
Linux troubleshooting, and technical documentation.
